How it is built

Plain HTML, CSS and JavaScript split across a few small files. No framework, no build step, no server.

Run it locally

Download the project and open index.html in your browser. That is all.

Host it for free

Push the files to a GitHub repository and turn on GitHub Pages. The README explains the steps.

Contribute

Ideas welcome: new games, word lists, languages and themes. Fork the project, make your change and send a pull request.
